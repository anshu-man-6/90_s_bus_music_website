# Route 90 SEO and Google Search Console launch checklist

## 1. Publish the website

The live Route 90 homepage is:

`https://nine0-s-bus-music-website.onrender.com/`

## 2. Set the real canonical and sharing URLs

The canonical URL, Open Graph URL, and structured-data URL have already been set to the live Render address. Add an `og:image` after you publish the current updated files.

## 3. Create sitemap.xml

`sitemap.xml` and its `robots.txt` reference are now included. Publish both files at the site root.

## 4. Add the property to Google Search Console

1. Open https://search.google.com/search-console.
2. Select **Add property** and choose **URL prefix**. Enter exactly: `https://nine0-s-bus-music-website.onrender.com/`.
3. Choose **HTML tag** or **HTML file** verification. A Domain property will not work unless you control DNS for `onrender.com` itself.
4. Copy the unique verification tag or upload file Google provides and send it to me if you want me to place it in the deployment files.
5. Open **Sitemaps**, enter `sitemap.xml`, and submit it.
6. Open **URL inspection**, enter the homepage URL, and select **Request indexing**.

## 5. Ranking plan

Use one clear primary search topic per page. This homepage is optimized for:

- Indian bus driver playlist
- roadways music player
- 90s Hindi bus songs
- Indian bus horn sound

Create separate useful pages—not copied content—for each topic, such as an about page, a local-music-player guide, and a bus-horn feature page. Earn genuine relevant links from transport, Indian music, or design sites. Monitor Search Console's Performance report monthly, then improve pages that receive impressions but low clicks.

No one can guarantee first-page Google ranking. Strong content, valid technical setup, real user value, and quality links are what improve the odds.
